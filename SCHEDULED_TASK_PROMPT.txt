## Data extraction

Same __NEXT_DATA__ / __APOLLO_STATE__ / CarsWeb.SearchController.index patterns documented in BUILD_NOTES_FOR_CLAUDE_CODE.md in the lexcars-site repo.

- **Cars.com:** title text matches ^Used (YYYY) (Make) (Model) (Trim). Body of srp_results is at CarsWeb.SearchController.index script id. **Listing URL:** <a href*="/vehicledetail/"> from the [data-listing-id] card, or https://www.cars.com/vehicledetail/{id}/. **Image:** result.gallery.images[0].url.
- **CarGurus:** cards are [data-cg-ft="srp-listing-blade"]; parent <a href*="/details/{id}"> for the id. Canonical URL https://www.cargurus.com/details/{id} (strip query string; never use the inventorylisting/...action form — it redirects). **Image:** <img> inside the wrapping link.
- **AutoTrader:** props.pageProps.__eggsState.inventory[id] has make.name (title-case UPPERCASE values), model.name, bodyStyles[0].name (filter "Convertible"). **Listing URL:** card <a href>; canonical https://www.autotrader.com/cars-for-sale/vehicle/{id}.

**Transmission (REQUIRED for every listing):** emit "transmission": "Manual" | "Automatic" | null.
- Cars.com: embedded-state transmission field, or infer from trim/title: 6A, 7A, 8A, Automatic, CVT, Tiptronic, SMG, DSG → Automatic; 5M, 6M, 5-Speed Manual, 6-Speed Manual, Manual → Manual.
- CarGurus: blade card spec text (often lists "Manual"/"Automatic").
- AutoTrader: inventory[id].transmission.name (or specifications block).
- If genuinely undetermined, use null — never guess.

**URL capture rule:** prefer the <a href> rendered on the SRP card over a constructed URL; strip query strings before storing.

## Image extraction — MANDATORY, all sites

Missing images were the #1 recurring defect (past audit: 79/99 listings null). Follow this exactly:

1. **Scroll EVERY results page top-to-bottom in 600px steps with 300ms delays BEFORE any DOM extraction** — Cars.com and AutoTrader lazy-load below the fold just like CarGurus. This applies to page 2 / firstRecord=25 pages too.
2. **Two-tier extraction per listing:**
   - Tier 1 — embedded state: result.gallery.images[0].url (Cars.com), inventory[id].images.sources[0].src (AutoTrader). AutoTrader's sources entries may be objects ({src}) or relative paths — resolve to absolute; if missing, go to Tier 2.
   - Tier 2 — DOM fallback: after scrolling, first <img> in the card, checking src, data-src, and the first URL in srcset. Skip any URL containing no-image-placeholder, spacer, blank, or a data: URI.
3. Strip query strings from all image URLs.
4. **Validation gate (BEFORE writing data.json):** count non-null imageUrl per source. If any source is below **80%**, redo Tier 2 for that source's nulls (re-scroll first). Log final per-source image coverage in introHtml if any source stays below 80%.
5. **Every top10, manual10, and mustangs pick MUST have a non-null imageUrl.** If a pick lacks one, open its detail page and grab og:image (max 5 detail-page visits per run); if it still has none, substitute the next-ranked listing that has an image.

## Ranking criteria for the top 10 (cheap fun 4-seat second car lens)

All picks must be 4+ seat convertibles (deny-list and personal exclude list already applied). In this order:

1. **Working top condition** — listings that describe top operation, recent reseal, new motor, etc. Torn fabric tops or yellowed plastic rear windows drop in rank.
2. **No rust mentioned, no flood / salvage history**
3. **Reliable model family** — Mustang V6/GT (2005+ strongly preferred), lower-trim BMW 3-series with documented service, Audi A3/S4 Cabriolet, Saab 9-3, Lexus IS C, Jaguar XJS. De-rank: Sebring/200 (fine but generic), VW Eos (roof-seal failures are expensive), PT Cruiser Convertible (chassis flex), high-mile Audi Cabriolet (electrics/CVT).
4. **Manual transmission preferred** — but auto OK
5. **Mileage flexible** — under 150k fine on the reliable families
6. **Distance** — closer is better, but 35 mi out for a great find beats 5 mi for a tired Sebring
7. **Sourcing diversity** — try not to make all 10 picks from one site

For each pick include:
- **rank**: 1–10
- **year, make, model, trim**: separate fields (do NOT supply a combined title)
- **price**: integer dollars; **mileage**: integer miles
- **location, dealer, source, url, dealRating, transmission, imageUrl**: same shape as listings above (imageUrl required — see image rules)
- **whyGood**: model strengths + this listing's particulars
- **whatToVerify**: convertible-specific PPI — full top cycle, headliner/carpet water stains, rear-window seam, rocker rust, plus model gotchas (Mustang: 8.8 axle clunk; BMW: oil leaks, soft-top hydraulic ram; Eos: roof drains + seals)
- **bottomLine**: one-sentence verdict

### 4. Build the JSON

⚠️ CRITICAL SCHEMA RULES — the page renders completely blank if these are wrong. A past run (2026-10-29) broke the site by getting both of these wrong; read carefully before writing.

**Rule A — Source data at TOP LEVEL, never nested.**
Write carscom, cargurus, autotrader, truecar as TOP-LEVEL keys in the JSON object.
WRONG (broke the site): { "sources": { "cars": {...}, "autotrader": {...} } }
CORRECT: { "carscom": {...}, "cargurus": {...}, "autotrader": {...}, "truecar": {...} }

**Rule B — top10, manual10, mustangs are OBJECTS with a picks array, not plain arrays.**
WRONG (broke the site): "top10": [ { "rank": 1, ... }, { "rank": 2, ... } ]
CORRECT: "top10": { "introHtml": "<p>...</p>", "picks": [ { "rank": 1, ... }, { "rank": 2, ... } ] }

**Rule C — Cars.com top-level key is exactly "carscom" (no dot, no space, no dash, no underscore).**
WRONG: "cars", "cars.com", "cars_com"
CORRECT: "carscom"

The full required shape:

{
  "lastRefreshed": "<ISO timestamp>",
  "filters": { "minPrice": 7000, "maxPrice": 15000, "radiusMi": 35, "zip": "19063", "minSeats": 4, "mustangMinYear": 2005 },
  "carscom":    { "totalFound": N, "url": "...", "listings": [...up to 30...] },
  "cargurus":   { "totalFound": N, "url": "...", "listings": [...up to 30...] },
  "autotrader": { "totalFound": N, "url": "...", "listings": [...up to 30...] },
  "truecar":    { "totalFound": 0, "url": "", "listings": [] },
  "top10":    { "introHtml": "<p>...</p>", "picks": [ ...10 pick objects... ] },
  "manual10": { "totalFound": N, "introHtml": "<p>...</p>", "picks": [ ...up to 10 pick objects... ] },
  "mustangs": { "totalFound": N, "introHtml": "<p>...</p>", "picks": [ ...up to 5 pick objects... ] }
}

totalFound = count on the site BEFORE the seat filter; note post-filter counts in introHtml.
